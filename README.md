# 标普500 每日决策看板

面向长期持有者：在合适的时候分批追加、在少数高点少量减持。看板每天给出四个概率，并配上因子、跨市场联动、当日新闻解读、近期变化原因、未来事件情景概率，以及1928年以来的长周期历史。

看板：https://claude.ai/artifact/KnPTAoUBXus6vty4GnX5dC

## 四个概率

| 概率 | 定义 | 方法 | 样本外AUC(1960起) |
|---|---|---|---|
| 追加概率 | 12个月后涨幅≥10% | 1000个最相似历史交易日的结果，向历史平均收缩1/3 | 0.54(较弱) |
| 12个月上涨概率 | 12个月后高于今天 | 同上 | 0.50(接近随机) |
| 减持概率 | 今天接近未来半年高点(未来最高不超过+2%)，且随后跌≥8% | 同上 | 0.55(较弱) |
| 3个月再跌≥10%风险 | 未来63个交易日内最低收盘比今天低10%以上 | L2正则化逻辑回归 | 0.67(有效) |

相似度用五个价格状态变量：距历史高点回撤、20日波动率(对数)、偏离200日线、近1个月涨跌、12-1个月动量；训练数据从1930年开始。

所有模型都做逐年滚动样本外检验：每年1月只用当时已知结果的数据重新拟合，再预测当年。12个月方向几乎无法预测，这与学术研究一致；短期下跌风险因为波动率聚集而有较稳定的预测力。最初版本加入了估值、利率、信用利差，滚动检验显示这些宏观因子与12个月回报的关系在不同年代方向相反(样本外AUC 0.41)，因此改为在因子面板中以“同区间历史条件概率”的形式展示，而不进入概率模型。

## 目录

```
snp/fetch.py     数据抓取(Yahoo Finance、FRED、multpl)，失败时回退到 data/raw 缓存
snp/model.py     特征、目标定义、相似状态模型、风险模型、滚动样本外检验
snp/factors.py   因子面板(当前值、历史分位、同区间条件概率)
snp/markets.py   跨市场行情、相关性、板块
snp/history.py   长周期历史：年度回报、熊市、持有期、事件研究、CAPE、季节性
snp/build.py     生成 out/*.json，并追加 data/signal_history.csv
snp/store.py     生成写入看板数据库的文档
dashboard/index.html   看板页面源码(写入 Artifact 的 files/index.html)
data/manual/notes.json 当日新闻、驱动、时间线、事件日历(Claude 每日整理)
docs/DAILY_UPDATE.md   每日更新流程
```

## 本地运行

```bash
pip install -r requirements.txt
python -m snp.build            # 抓取最新数据并计算
python -m snp.build --cached   # 只用 data/raw 缓存重算
```
